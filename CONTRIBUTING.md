# Contributing

This is a small SYNTHETIC research toy; issues and pull requests are
welcome.

- Run `python -m unittest` and `python scripts/check_text.py` before you
  open a pull request. Runtime code stays standard-library only.
- Every random draw must come from an explicit seed. Study seeds live in
  `experiments/common.py`; the development, confirmation and smoke sets
  are disjoint and seed 42 is reserved for the committed scenes.
- If you change anything that feeds a scene, regenerate the WAV files
  with `python -m membrane_listen` and commit them with the change; the
  test suite compares regenerated bytes with the committed files.
- Keep claims honest: label results SYNTHETIC, report null results, and
  never describe outputs as recordings, ECG, EEG, medical or clinical.
  No claim about what a listener hears without a listening test.
- Optional plotting or numerical libraries may be used in dev-only
  scripts but must not become a runtime dependency.
- Commit messages: imperative mood, one logical change per commit.
- Contributions are accepted under AGPL-3.0-only.
